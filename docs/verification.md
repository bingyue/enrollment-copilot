# MVP 验收记录

验收日期：2026-10-07（Asia/Shanghai）。

- 生产服务：`http://127.0.0.1:3210`，使用 `npm start` 运行。
- 首次演示数据：50 条线索、5 门课程、7 名学员、销售待办与 4 段质检案例。

端到端流程覆盖：

1. 咨询导入 → 画像 → 课程匹配 → 评分依据 → 回复记录 → 四步跟进 → 确认报名 → 学员运营 → 刷新持久化。
2. 课程价格维护、全局搜索、空结果、任务内容调整和完成状态。
3. 批量对话导入、风险筛选、原始证据与报告保存。
4. 人工修改画像、生成学员关注名单、创建运营待办。
5. 七页面移动端加载、菜单操作与浏览器异常检查。
6. 无效咨询、跨站写入、无效报名课程均不改变工作区。

自动验收使用独立端口和数据文件，未把测试咨询留在客户演示工作区。
