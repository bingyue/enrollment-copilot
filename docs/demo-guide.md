# 3 分钟演示：知遇招生工作台

演示地址：http://127.0.0.1:3210 。无需模型密钥；顶部和分析卡片明确显示演示模式。

## 00:00–00:25 今天先跟谁？

首页展示“今天哪些学员最值得跟进？”。简要指向新增线索、高意向、今日跟进和成功报名。数据会随操作变化，并非固定截图数字。

点击“录入新咨询”，然后“填入演示案例”。

## 00:25–01:15 从咨询到下一步

点击“分析并建立档案”，系统保存新线索并进入三栏工作台。

- 左侧：新学员与意向等级。
- 中间“学员画像”：28 岁产品经理、零基础、预算 5000、每周 6 小时、本周决策。
- “课程方案”：AI 产品经理成长营；同时展示预算、基础、时间依据以及暂不优先推荐的课程。
- 右侧“评分依据”：七项分值、每项依据。强调是意向分，不是保证成交的概率。
- 回到“行动建议”，展示价格与学习基础顾虑，点击“采用回复”。

修改一句话并保存沟通记录。系统会自动依据新沟通刷新建议，但不会自动给学员发消息。

## 01:15–01:40 7 天跟进与报名

打开“跟进计划”，展示第 0、1、3、7 天安排。在“跟进任务”可以改日期、改内容、标记完成或等待回复。

回到该线索，点击“确认报名”，选择 AI 产品经理成长营，确认。此操作只记录报名，不发起支付。

## 01:40–02:15 成交之后仍然有人管

点击“进入学员运营”。刚报名的学员已经出现，默认开课日期为 3 天后，可在“更新进展”中修改。

更新学习进度、作业、活跃度，查看关注建议变化。点击“生成今日关注名单”，再对风险学员“生成运营待办”。

进度较高、体验良好的学员可以标记进阶续费和转介绍机会。

## 02:15–03:00 团队销售质检

打开“销售对话质检” → “批量导入对话” → “填入 4 段演示对话” → “开始质检”。

- 哪些咨询有学习需求，但老师没有继续推进？
- 哪位老师没有接住价格顾虑？
- 哪段回复出现了“保证就业”等不当承诺？
- 哪些沟通策略出现在较好的报名结果里？注意小样本不代表因果。

点击“查看证据与建议”，展示原始话术和改进建议。所有报告可保存和导出。

## 重复演示

设置页面可以导出完整备份，或明确确认后恢复 50 条演示数据。测试使用独立文件，不会清空演示工作区。

## 批量文本导入格式

```text
顾问=林老师;学员=小周;结果=未知
学员：我想学AI产品设计，预算5000，有点担心课程效果。
老师：我们先确认一下基础和学习目标，您每周能投入多少时间？
---
顾问=陈老师;学员=小李;结果=未报名
学员：我想学Python，零基础。价格有点贵。
老师：都是这个价，您考虑好了再联系。
```

使用 `学员：` 和 `老师：` 标记消息角色。结果可为“未知 / 已报名 / 未报名”，不知道就保留未知。一次最多 20 段、单段最多 12,000 字。
